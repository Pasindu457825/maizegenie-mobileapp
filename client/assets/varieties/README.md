# Maize Variety Images

This folder should contain images for each maize variety used in the Yield Prediction feature.

## Required Images

Please add the following image files (PNG format, recommended size: 320x240px):

1. **jet999.png** - Jet 999 variety
2. **pacific808.png** - Pacific 808 (C.P.808) variety
3. **gt709.png** - GT 709 variety
4. **gt200.png** - GT200 variety
5. **commando.png** - Commando variety

## Image Guidelines

- **Format:** PNG or JPG
- **Size:** 320x240 pixels (4:3 aspect ratio)
- **Quality:** High-resolution photos showing the maize cobs or plants
- **Background:** Clean, preferably agricultural field background
- **Naming:** Lowercase, no spaces (as specified above)

## Temporary Placeholder

Until actual images are added, you can use placeholder images from online sources or create simple colored placeholders.

## Usage

These images are used in:
- `client/src/components/forms/VarietySelector.tsx`
- Displayed in the Crop Information screen (Step 2 of Yield Prediction)
